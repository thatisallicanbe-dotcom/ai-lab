# 강원 곁에 — AI 기반 맞춤형 생활정보 안내 (시제품)

My AI 랩 프로젝트 참가작(팀 로컬브레인)의 웹 시제품입니다.
강원 주민, 특히 어르신이 버튼 하나로 필요한 정보를 찾고, 떨어져 사는 자녀와 안부를 나눌 수 있게 하는 것이 목표입니다.

## 화면

| 화면 | 내용 |
| --- | --- |
| 홈 | 말로 물어보기, 병원·화장실 버튼, 나 괜찮아요(부모), 받은 정보 카드, 글씨 크기 3단계 |
| 물어보기 | 질문하면 관련 지원제도·시설로 안내, 출처·수집일 표시, 읽어주기 |
| 나에게 맞는 지원 | 사는 곳·나이대·필요한 도움을 고르면 지원제도 목록과 상세(대상·서류·신청 방법) |
| 병원·화장실 | 현재 위치에서 가까운 3곳, 열림 여부, 지도, 길찾기(카카오맵) |
| 가족 | 부모/자녀 설정, '나 괜찮아요' 안부·위치·최근 찾아본 정보를 링크로 공유, 자녀가 지원제도 정보 보내기 |

## 공공데이터 연결

`.github/workflows/update-data.yml`이 매일 한국시간 03:17에 `scripts/fetch_data.py`를 실행해
아래 API를 호출하고 결과를 `data/*.json`으로 저장한 뒤 사이트(`gh-pages`)에 반영합니다.
웹앱은 이 파일을 읽고, 파일이 없으면 샘플 데이터를 씁니다.

| 파일 | API (공공데이터포털) |
| --- | --- |
| data/programs.json | 행정안전부_대한민국 공공서비스(혜택) 정보 (중앙부처·공공기관 + 강원 지자체만) |
| data/hospitals.json | 국립중앙의료원_전국 병·의원 찾기 서비스 → 실패 시 건강보험심사평가원_병원정보서비스 |
| data/toilets.json | 행정안전부_공중화장실정보 조회서비스 (좌표는 OpenStreetMap Nominatim으로 조금씩 변환) |

**인증키는 코드에 넣지 않습니다.** 저장소 Settings → Secrets and variables → Actions에
`DATA_GO_KR_KEY` 이름으로 공공데이터포털 인증키를 등록하세요. 각 API는 포털에서 따로 활용신청해야 합니다.
수동 실행: Actions 탭 → "공공데이터 수집" → Run workflow. 결과 요약은 `data/meta.json`에 남습니다.

## 시제품의 한계 (다음 단계)

- 수집이 성공하기 전까지는 샘플 데이터가 보입니다.
- **AI 모델 미연결.** 지금은 키워드로 샘플 자료를 찾아 답합니다. 다음 단계에서 LLM + 검색(RAG)으로 바꿉니다.
- **가족 공유는 링크 방식.** 서버 없이 카카오톡·문자로 링크를 보내 공유합니다.
  '마지막 사용 시각' 자동 확인은 서버(Supabase 등)를 붙인 뒤 구현합니다.
- 음성 입력·읽어주기는 브라우저의 Web Speech API를 사용하며, 브라우저마다 지원 여부가 다릅니다.

## 실행

빌드가 필요 없는 정적 사이트입니다. `index.html`을 열거나 GitHub Pages로 배포합니다.

```
python3 -m http.server 8000
```
